# pgxexec

[![PkgGoDev](https://pkg.go.dev/badge/github.com/krhubert/pgxexec)](https://pkg.go.dev/github.com/krhubert/pgxexec)

Package pgxexec provides a unified interface for executing SQL queries
and transactions using pgx. It is designed to work seamlessly
with sqlc-generated code, allowing an easy integration.
